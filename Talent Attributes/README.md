# Signal — On-Air Talent Scorecard

Open `on-air-talent-scorecard.html` in any current desktop browser to use the application.

## Included

- Demo sign-in with browser-local persistence
- Talent directory with search, filters and sorting
- Create, edit and delete talent evaluations
- All 29 assessment attributes, scored from 1–10
- Automatic totals, averages and recommendation bands
- Strengths, development opportunities and coaching plans
- Leaderboard and team capability overview
- Side-by-side comparison of up to six people
- Radar charts
- CSV download and print-to-PDF comparison reports

This is a self-contained browser application: it does not send data to a server. Evaluation data is stored only in the browser profile used to open it.
