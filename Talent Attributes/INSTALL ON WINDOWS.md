# Install Talent Attributes on Windows

This app is complete and does not need a technical installation.

## Option 1 — Use it like an app (recommended)

1. Create a folder in `Documents` called `Talent Attributes`.
2. Copy these two files into that folder:
   - `on-air-talent-scorecard.html`
   - `Launch Talent Attributes.cmd`
3. Double-click `Launch Talent Attributes.cmd` whenever you want to open the app.
4. To put it on your desktop, right-click `Launch Talent Attributes.cmd`, choose **Show more options** if that appears, then choose **Send to → Desktop (create shortcut)**.
5. Rename the desktop shortcut to `Talent Attributes` if you wish.

## What happens to your data

The app saves evaluations in the browser on that computer. Use **Export CSV** regularly to keep a backup of the data.

Do not clear your browser's site data if you want to keep saved evaluations.

## Use it

1. Open the app.
2. Enter your name and select **Open scorecard**.
3. Select **New evaluation** to add an on-air personality or candidate.
4. Complete the 29 ratings, notes and recommendation, then select **Save evaluation**.
5. Use **Talent directory** to find saved profiles and **Compare talent** to view profiles together and print a PDF report.

## Files to keep together

Keep the launcher and the `.html` file in the same folder. The launcher opens the app file beside it.
